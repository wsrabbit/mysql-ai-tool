# 交互式连接向导

安装后在普通 PowerShell 中执行安装脚本显示的命令：

```powershell
$mysqlAi = Join-Path $env:LOCALAPPDATA 'mysql-ai-tools/versions/0.3.0/app/mysql-ai.exe'
& $mysqlAi config wizard
```

自定义安装目录时，请同时指定对应配置目录：

```powershell
& 'C:\自定义目录\versions\0.3.0\app\mysql-ai.exe' --home 'C:\自定义目录' config wizard
```

源码环境运行 `uv run --no-sync mysql-ai config wizard`。向导要求交互终端；
管道输入、MCP 工具调用和无交互 CI 应继续使用 `config add`。

## 新建连接

1. 输入唯一别名（字母、数字、下划线或连字符）。
2. 输入服务器地址、端口、用户名和环境名称；回车采用界面显示的默认值。
3. 明确输入允许访问的数据库，多个库用逗号分隔。系统库不能作为业务库配置。
4. 选择 TLS：系统信任证书、自定义 CA，或仅本机测试禁用 TLS。默认验证证书和主机名；
   向导只允许 localhost、127.0.0.1、::1 在明确确认后禁用 TLS，不自动降级。
5. 隐藏输入密码两次。两次不一致时重输；终端不支持隐藏输入时停止，避免密码回显。
6. 自动验证每个指定数据库，显示网络、认证、TLS 和权限检查结果。
7. 核对摘要，输入 y 确认保存。默认不确认。

成功后按提示重启 MCP 或新建 Codex 会话，例如：“使用 dev 连接查看 shop 的表结构。”

## 修改连接、失败与取消

已有连接时，可选择修改并输入别名。基础字段默认显示旧值，回车保留。
密码可选择保留原凭据来源，或输入新密码；原配置使用环境变量时也可以保留该来源。
向导不会显示原密码，不会把密码放到环境变量或临时配置中。

检查失败后，按菜单修改基础信息、数据库、TLS 或密码，再选择重试验证。
任何字段修改都会清除之前的本次验证结果。若暂时没有网络，可明确选择未验证保存，
随后仍需确认保存。此操作不改变 TLS 或数据库权限设置。

“通过 / 未验证”描述本次向导检查，返回结果含 `verified`；不持久化为长期健康状态。
配置格式保持兼容，未来需要确认连接时请运行 `doctor --connection 别名`。

Ctrl+C、输入结束或菜单取消均会退出。确认保存前不修改连接或凭据。
确认后采用先保存新凭据、再原子写入配置的流程；配置写入失败时清理新凭据，保留旧连接。
保存成功后才清理不再被其他连接引用的旧凭据，清理失败只提示，不撤销新配置。

如果中断恰好发生在配置已经落盘之后，工具会确认保存结果并保留有效凭据。
配置目录中的 `connections.json.lock` 是持久的锁文件；退出进程会释放锁，不要通过删除文件解锁。

## 常见提示

| 提示 | 操作 |
|---|---|
| AUTH_FAILED | 修改用户名或密码，再重试 |
| CONNECTION_FAILED | 修改地址/端口，检查网络 |
| TLS_FAILED | 检查 CA 路径与服务器证书主机名 |
| PERMISSION_DENIED | 检查该数据库的只读授权，或修正数据库列表 |
| SCHEMA_CHANGED | 检查数据库名称是否存在 |
| CONFIG_CHANGED | 其他进程改过配置，重新启动向导读取最新内容 |
| CONFIG_BUSY | 另一个进程正在保存，稍后重试 |
| CREDENTIAL_BACKEND | 检查当前 Windows 用户的凭据存储 |
| CREDENTIAL_CLEANUP / SAVE_UNCERTAIN | 按提示在本机检查配置和本工具凭据，不要提交密码 |

配置写入使用进程锁和保存前快照比较，保护本版本命令之间的并发修改。
外部编辑器不遵循锁协议，保存过程中请避免手工编辑配置文件。
向导测试只检查连接与可见权限，不证明所有表和视图均可查询；权限诊断提示不是完整权限证明。

## 自动与人工验证

单元测试使用可替换的终端输入输出，覆盖重试、取消、保留凭据、失败回滚和并发保存。
Docker 集成测试验证多数据库访问、错误密码、部分库无权限、TLS 拒绝，以及向导验证后保存。
Windows 发布包检查向导命令存在并拒绝非交互输入；真实终端的密码不回显与交互体验仍需实际检查。
